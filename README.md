# Robot Grid Navigation

## Project Description

This project implements a robot navigation system on a grid. The robot moves from a starting position to a target position while avoiding obstacles.

## Project Structure

* `src/` - Source code
* `tests/` - Test cases
* `docs/` - Documentation and screenshots
* `README.md` - Project information
* `REPORT.md` - Project report
* `requirements.txt` - Python dependencies
* `.gitignore` - Files ignored by Git
* `LICENSE` - Project license

## How to Run

1. Install Python.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Run the program from the `src` folder.

## Testing

Run the tests using:


pytest
